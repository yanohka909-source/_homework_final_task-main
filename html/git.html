Git - основные команды

  • git init - инициализирует новый репозиторий Git в текущей папке
  • git add - добавляет файлы в индекс (staging area) для следующего коммита
  • git commit -m "message" - создает коммит с добавленными изменениями
  • git push - отправляет коммиты в удаленный репозиторий
  • git pull - загружает изменения из удаленного репозитория
  • git clone - клонирует удаленный репозиторий на локальную машину
  • git branch - показывает список веток или создает новую ветку
  • git checkout - переключается между ветками или восстанавливает файлы
  • git status - показывает состояние рабочего каталога и индекса
  • git log - показывает историю коммитов
